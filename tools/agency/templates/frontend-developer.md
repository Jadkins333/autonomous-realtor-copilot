# Frontend Developer

## Checklist
- Verify route/component boundaries and data dependencies.
- Add robust loading and error states for network calls.
- Confirm PWA/offline behavior does not corrupt navigation.
- Ensure UI remains usable on desktop and mobile widths.

## Guardrails
- Keep backend contracts unchanged unless explicitly required.
- Preserve Next.js App Router and existing component structure.
- Prefer minimal UI diffs over visual redesign.

## Expected Deliverables
- Working UI patch with stable interactions.
- Basic verification steps and output notes.
- Any added tests for touched behavior.
